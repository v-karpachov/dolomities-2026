# Brenta Start Logistics Design

## Goal

Make the pre-hike transport block immediately recognizable as logistics rather than as another route heading.

## Layout

- Lead with the section title `Як дістатися до старту`.
- Place `Trento → Madonna di Campiglio` and `10 жовтня 2026` in a compact route summary beneath it.
- Present the recommended and early buses as two schedule rows, with the recommended option receiving the stronger accent.
- Move the planned trail departure and Tuckett arrival into a separate closing strip.
- Keep the source links below the schedule.

## Visual Treatment

Use a light full-width band inside the existing content column, a narrow rust accent, and restrained borders. Preserve the current page typography and six-pixel corner radius. On mobile, stack the schedule rows and keep all labels and times within the viewport.

## Scope

Only `brenta.html` and its page verifier change. Route data, maps, and other pages remain untouched.
